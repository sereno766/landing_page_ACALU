# Acalu Sereno · portfólio

Site pessoal de Acalu Sereno, desenvolvedor de automação com IA. Publicado em [serenosdev.vercel.app](https://serenosdev.vercel.app/).

HTML, CSS e JavaScript puros, sem build. Para ver localmente, abra o `index.html` no navegador ou sirva a pasta com qualquer servidor estático.

## Arquivos

- `index.html`: a página inteira, com o diagrama do fluxo do n8n em SVG.
- `styles.css`: cores, tipografia (Imbue e Albert Sans, do Google Fonts) e layout.
- `main.js`: entradas das seções, filtro dos trabalhos, a demonstração do fluxo de e-mails e a lista da trajetória.
- `assets/`: foto, imagens de arquivo e a filmagem de 1947. Os créditos ficam em `assets/credits.json` e no rodapé do site.

## Conteúdo de exemplo

Os e-mails da demonstração, a avaliação do Google e o perfil de influenciador são exemplos. Os números de resultado (4.000 avaliações, 30 comércios, taxa de resposta de menos de 50% para 100%) são reais.
